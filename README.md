# React CV Generator

A React web application for building a CV, previewing the result, and exporting it as a PDF.

**Live demo:** https://react-cv-generator-eight.vercel.app/

## Features

- Editable personal information and CV sections
- Live CV preview
- Optional profile picture and GitHub profile link
- PDF export using html2pdf.js
- Responsive layout and custom CSS

## Tech stack

- React 19
- Vite 6
- React Router
- html2pdf.js
- CSS

## Requirements

- Node.js compatible with Vite 6 (Node.js 18+ recommended)
- npm

## Run locally

    git clone https://github.com/dhia336/React-Cv-Generator.git
    cd React-Cv-Generator
    npm install
    npm run dev

Vite prints the local development URL in the terminal, usually http://localhost:5173.

## Production build

    npm run build
    npm run preview

The production build is generated in dist/.
